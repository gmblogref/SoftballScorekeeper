# Softball Scorekeeper

Softball Scorekeeper is a lightweight scorekeeping application for adult slow-pitch softball.

The application is intended to provide fast, simple, offline scorekeeping with automatic team statistics and custom beer-rule tracking.

## Technology Stack

- .NET 8
- .NET MAUI
- C#
- XAML
- Android
- Windows
- Git
- GitHub

## Build Requirements

- Visual Studio 2022
- .NET Multi-platform App UI development workload
- .NET 8 SDK
- Android SDK for Android builds
- Windows Developer Mode for local Windows deployment

## Current Status

The project currently contains the default .NET MAUI application template.

No application functionality, business logic, database integration, or custom architecture has been implemented yet.
