# Security Policy

Softball Scorekeeper is maintained as a personal project. Security reports will
be reviewed as time permits; no response or remediation service level is
promised.

## Supported versions

| Version | Security attention |
| --- | --- |
| Current `main` and Version 1.0.1 | Yes |
| Older, superseded, or prerelease builds | No guaranteed attention |

The latest published release is Version 1.0.1. Users should reproduce an issue
against the latest supported release when practical.

## Reporting a vulnerability

Do not publish vulnerability details, proof-of-concept exploits, credentials,
private data, or personal information in a public issue, pull request, or
discussion.

GitHub Private Vulnerability Reporting is enabled for this repository. Use the
**Report a vulnerability** option under the repository's Security advisories to
submit a report privately. Include the affected version, impact, reproduction
steps, and any suggested mitigation.

Please allow reasonable time for the owner to assess and address the issue
before public disclosure.
