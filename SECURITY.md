# Security Policy

Softball Scorekeeper is maintained as a personal project. Security reports will
be reviewed as time permits; no response or remediation service level is
promised.

## Supported versions

| Version | Security attention |
| --- | --- |
| Current `main` and the latest 1.0.x release | Yes |
| Older, superseded, or prerelease builds | No guaranteed attention |

The current published release is Version 1.0.0. Users should reproduce an issue
against the latest supported release when practical.

## Reporting a vulnerability

Do not publish vulnerability details, proof-of-concept exploits, credentials,
private data, or personal information in a public issue, pull request, or
discussion.

No public private-reporting channel or personal security contact address is
currently configured. A private channel must be configured before this
repository is made public. The recommended channel is GitHub Private
Vulnerability Reporting.

Once the repository is public and the **Report a vulnerability** option is
available under the repository's Security advisories, use that form to submit
the report privately. Include the affected version, impact, reproduction steps,
and any suggested mitigation. If that option is absent, do not publish the
sensitive details; ask the repository owner for a private reporting channel
without including vulnerability details.

After private reporting is configured, please allow reasonable time for the
owner to assess and address the issue before public disclosure.
